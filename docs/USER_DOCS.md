# User Reference & Application Guide

Welcome to AI Tools Hub. This manual describes how to navigate the website, understand account tiers, and get the most out of our free web tools.

---

## 1. Membership Tiers & Usage Limits

We are committed to providing free tools to everyone. To protect our servers and guarantee high performance, the platform enforces usage tiers:

### A. Guest Tier (Unauthenticated)
-   **Limits**: Guests are permitted to run **up to 10 tool operations per day** (such as percentage calculations, PDF conversions, or text comparisons).
-   **Tracking**: Guest runs are tracked securely via browser `localStorage` tokens.
-   **Limit Prompt**: When a guest reaches their 10-run limit, they will see a friendly prompt suggesting they sign up or sign in to remove all limits.

### B. Registered Tier (Authenticated Users)
-   **Limits**: **100% Free, Unlimited usage** with zero caps.
-   **Sign-Up Method**: Users can sign up securely using their Google Account in one click. No password setup is required.
-   **Added Features**:
    -   *Tool Favorites*: Bookmark any tool for quick access from the primary Dashboard.
    -   *Execution History*: Automatically track and review past runs, file comparisons, or output history under the Account Profile tab.

---

## 2. Navigating the Site

AI Tools Hub is designed for simplicity, speed, and mobile responsiveness:

-   **Global Search Bar**: Instantly filter and search over 50 tools using natural language (e.g., typing "VAT" or "PDF").
-   **Categorized Layout**: Browse tools grouped logically into Categories like *Developer*, *SEO*, *PDF*, *Images*, and *Daily Utility*.
-   **Tool Favorites**: Click the Heart icon on any Tool Page to add it to your personalized shortcuts panel on the main Dashboard.
-   **Breadcrumbs**: Every page includes a breadcrumb header (e.g., `Home > SEO Tools > Meta Tag Checker`) to easily trace your location.
-   **Sharing & Copy Links**: Share any tool with colleagues using the programmatic "Share" or "Copy Link" buttons next to the tool titles.
-   **E-E-A-T Transparency**: Learn more about our editorial and engineering standard by viewing the Author pages linked at the bottom of blog articles.
-   **History Log**: View, filter, or purge your personal execution history at any time from your Account Settings page.
